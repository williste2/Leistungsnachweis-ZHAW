# Data

The current dataset is the NYC Parking Violations Issued fiscal year 2021 CSV.
Download it from:

https://www.kaggle.com/datasets/new-york-city/ny-parking-violations-issued

Place the CSV at:

`data/Parking_Violations_Issued_-_Fiscal_Year_2021.csv`

The dataset directory is ignored by Git because the CSV is large and is not committed to the repository.
